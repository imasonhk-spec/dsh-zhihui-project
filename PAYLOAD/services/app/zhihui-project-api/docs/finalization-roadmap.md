# 项目最终收尾排期

## 目标

在保持现有业务模块可运行的前提下，补齐未完成能力。每个版本必须通过类型检查、生产构建、API/页面回归和测试数据清理后才能进入下一版本。

## 范围原则

- 不使用当前数据或静态 Mock 冒充“较上周变化”。
- 导出默认导出当前筛选结果，并在文件名和页面文案中明确。
- 已有数据库结构优先复用；新增表必须提供迁移和种子兼容。
- 每个版本独立可发布，不等待后续版本才形成基本闭环。

## 排期

### F1：基础收尾与通用导出（2 个开发日）【已完成】

- 建立统一 CSV 导出工具。
- 里程碑计划导出。
- 风险台账导出。
- 报批台账导出。
- 项目总览导出当前项目组合摘要。
- 复核协调事项现有导出口径。
- 验收：文件可下载、UTF-8 BOM、字段完整、筛选口径明确、类型检查和构建通过。

### F2：项目与阶段管理（8 个开发日，另预留 2 个缓冲日）【已完成】

- D1：冻结项目/阶段字段、状态、权限和接口契约。
- D2-D3：项目新增、编辑、归档/恢复；阶段列表、新增、编辑、排序、安全删除。
- D4：补校验、事务、重复编码/引用保护，并统一项目/阶段及业务变更审计和 actor 上下文。
- D5-D6：前端项目创建/编辑/归档恢复入口和阶段维护页面/抽屉。
- D7：类型检查、迁移/种子兼容、API smoke 和核心页面回归。
- D8：问题修复、验收和发布资料；D9-D10 作为兼容性及回归缓冲。
- 事务、项目隔离、重复编码和审计日志。
- 验收：CRUD、无操作不写审计、跨项目拒绝、归档默认隐藏、页面刷新同步。

### F3：原始页面面板补齐（3 个开发日）【已完成】

- 里程碑明细卡片独立面板。
- 里程碑延迟与到期预警面板。
- 报批时间轴和关键节点卡片复核/补齐。
- 风险、协调、报批页面统一当前态势摘要文案。
- 验收：与原 HTML 信息架构一致，使用真实 API 数据，不伪造历史。

### F4：真实历史变化分析（4 个开发日）【已完成】

- 复用 audit_logs 活动接口，按项目、实体类型和时间区间查询真实变更。
- “本周”采用自然周边界；新增统计接口聚合总变更、实体类型和动作，并在项目详情展示新增、状态变更、完成/关闭统计。
- 空区间返回零统计并明确无真实变化，不从当前实体状态反推历史。

### F5：任务依赖与甘特图（5 个开发日）【已完成】

- 任务依赖列表、新增、删除；同项目校验、自依赖/重复依赖、环检测和审计。
- 任务编辑弹窗维护前置依赖。
- 任务列表/甘特图切换；使用真实计划日期绘制任务条，缺失日期任务明确列出且不推测日期。
- 关键路径与依赖连线的高级计算暂不纳入本增量，后续可基于现有依赖 API 扩展。

- 任务依赖 CRUD。
- 环检测、自依赖和跨项目依赖拒绝。
- 任务甘特图、依赖线和关键路径基础计算。
- 验收：依赖增删、循环拒绝、日期缺失、父子任务和筛选联动。

### F6：审计、通知和导入（6 个开发日）【进行中】

- 已完成：项目审计查看页面，支持实体类型、时间范围筛选及真实活动记录加载/错误/空状态。
- 已完成：导入任务登记与项目隔离查询页面，展示状态、行数和错误摘要；任务记录默认 pending。
- 已完成：通知页面/API 的最小活动映射视图和项目隔离标记已读接口；当前数据来自 audit_logs，已读状态尚未持久化。
- 已完成：任务类 CSV 文件的 multipart 预览、列/行校验、逐行执行、成功/失败统计与 import_job 状态回写。
- 已完成：任务类 `.xlsx`/`.xlsm` 第一工作表导入，CSV 与 Excel 共用表头/行校验和执行链路；`.xls` 等不支持格式明确返回 415。
- 已完成：风险类 CSV/`.xlsx`/`.xlsm` 导入预览与执行，校验风险级别、状态、日期和必填字段，并复用真实风险创建与审计链路。
- 已完成：里程碑类 CSV/`.xlsx`/`.xlsm` 导入预览与执行，校验类型、状态、日期和必填字段，并复用真实里程碑创建与审计链路。

- 回归说明：通知已读接口在前端以 `{}` 请求体调用时返回成功；当前已读仍不持久化。

- 项目审计日志查询页面和筛选。
- 站内通知表、生成规则、已读/未读和催办入口。
- CSV/Excel 导入预览、校验、执行、错误行和任务状态。
- 验收：权限/项目隔离、幂等、错误恢复、导入结果与审计一致。
